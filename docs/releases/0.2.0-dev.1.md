# gcode_core 0.2.0-dev.1：首个 macOS 预发布版

此版本供其他 Flutter 项目通过 Git 固定 tag 接入。发布渠道为 GitHub Release，
不是 pub.dev；定位为 macOS 预发布版本，不宣称三端稳定支持。

## 本版能力

- G0 虚线、G1 实线、未播放路径、段内进度、网格、原点、刀头和光晕统一由 Flutter GPU 绘制。
- Flutter 仅合成 GPU 图像并显示普通 UI，不保留 Canvas 几何绘制后端或降级能力。
- 保留现有逐行读取、错误收集、G0/G1/G90/G91 解析、轨迹构建、时间线和播放控件；未重构快照管线。
- 修复颜色格式、透明度、管线绑定残留及非零/负 Y 坐标映射问题。
- 示例集成局部 Xcode 编译器探测及 macOS 构建环境兼容处理，覆盖普通 Flutter/IDE 启动路径。

## 项目引用

```yaml
dependencies:
  gcode_core:
    git:
      url: https://github.com/lizy-coding/gcode_core.git
      ref: v0.2.0-dev.1
```

最低 Flutter 约束为 3.47.2，本版实际验证使用 Flutter 3.47.2 / Dart 3.13.2。
macOS 构建 deployment target 至少 12.0，实际运行证据来自 macOS 26.5 arm64。
宿主需在 `macos/Runner/Info.plist` 顶层 dict 开启：

```xml
<key>FLTEnableImpeller</key>
<true/>
<key>FLTEnableFlutterGPU</key>
<true/>
```

shader asset 随 package 自动打包，无需手动复制。宿主文件选择及沙盒文件访问权限由宿主负责。
example 的 Xcode/Pod 配置不会随依赖自动注入其他项目；只有出现相同编译器阻塞或部署目标冲突时才采用对应兼容处理。

## 不兼容改动

比较基线为改造前的 `7a52281`（包版本 0.1.0）：

| 旧用法或行为 | 新用法或影响 |
| --- | --- |
| 较旧 Flutter SDK | 最低 Flutter 3.47.2；只使用解析 API 的消费者也受包级约束 |
| 不启用 GPU 也能绘制 | 必须启用 Flutter GPU/Impeller；失败直接报错，无降级 |
| rapidMovePaint / rapidMoveBgPaint | rapidMove / rapidBackground，值为 GcodeStroke |
| linearMovePaint / linearMoveBgPaint | linearMove / linearBackground，值为 GcodeStroke |
| gridPaint / originPaint | grid / origin，值为 GcodeStroke |
| toolHeadPaint / toolHeadGlowPaint | toolHeadColor / toolHeadGlowColor，值为 Color |
| originDotPaint | originDotColor，值为 Color |
| 原地修改 Paint | 创建新的不可变 GcodeStyle；线宽使用 width |
| 自定义 Paint shader/cap/blend 等 | 不再暴露任意 Paint 属性，使用本版固定绘制语义 |
| 原地修改 segments 列表 | 数据变化时替换列表，避免沿用旧 GPU 几何缓存 |
| 旧截图期望 | 坐标修正、裁剪、抗锯齿、图例及空状态可能变化 |

`GcodeCanvas` 的主要构造参数相对于 7a52281 未变。`backend` 和
`GcodeCanvasBackend` 只影响使用过中间开发迭代的项目，并非旧版正式 API。
公共解析、轨迹构建和快照接口未变。该包依赖 Flutter，不是纯 Dart CLI 包。

## 验证与已知限制

- GPU-only 实现已有 36 个单元测试、macOS Profile/Release 窗口、0%/45%/100% 图像检查及 20 次重建/尺寸变化证据。
- 本次发版执行了普通 `flutter build macos --debug` 和 `--release`，两者通过；36 个测试和静态分析通过。
- 已通过独立消费者的 Git 依赖解析、Dart 编译及 shader 资源打包检查。
- 一万段整图可绘制，但 GPU-only 两轮 60 秒采样帧数为 896/1610，不能宣告持续 60 fps；较低单帧耗时不替代帧率验收。
- Windows、Android 尚无实机验收，不包含在本次 macOS 支持声明中。
- 长时间显存趋势、更多 GPU/驱动和多显示器组合、磁盘及快照负载尚未覆盖。

完整历史证据见 [GPU 独占验收](../macos-gpu-only-acceptance.md)。
